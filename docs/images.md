# Images & rights

Every image under `public/images/` must have a record in `content/images.json`; the audit and the build fail otherwise.

## Record fields

| Field | Notes |
| --- | --- |
| `src`, `width`, `height` | Dimensions prevent layout shift |
| `alt` | Describe what's shown, naturally. No keyword stuffing, no "image of" |
| `kind` | `illustration`, `photograph`, `product-photo`, `graphic` |
| `source` | `original`, `unsplash`, `pexels`, `pixabay`, `amazon-api`, `brand-press-kit`, `other` |
| `sourceUrl`, `creator` | Required for third-party images (creator required when attribution is required) |
| `license`, `licenseUrl`, `attributionRequired` | Copy the license terms as they were when you downloaded |
| `depictsSpecificProduct` | Must be `false` for illustrations |
| `rightsVerifiedAt` | Date you checked the license |

Third-party credits render automatically under the image; illustrations are labeled "Illustration".

## Current library

Fourteen original illustrations in `public/images/editorial/`, generated by `scripts/generate-brand-assets.ts` (kit in `scripts/brand/illustrations.ts`). They depict generic product types only.

## Adding stock photography

1. Prefer [Unsplash](https://unsplash.com/), [Pexels](https://www.pexels.com/) or [Pixabay](https://pixabay.com/). Read the **current** license page for the specific image — don't assume.
2. Download the original (don't hotlink), name it descriptively (`gua-sha-stone-on-linen.webp`), convert/resize to WebP ≤ 2000px wide.
3. Save under `public/images/photos/` and add a record with `sourceUrl`, `creator`, `license`, `licenseUrl`, `rightsVerifiedAt`.
4. Don't use stock photos in a way that implies you tested a product, and keep lifestyle photos visually distinct from product photos.
5. Never use magazine images, competitor images or images found in search results without a license.

## Product photos

Only via a permitted channel — e.g. Amazon's Product Advertising/Creators API under its display rules, or a brand press kit whose terms allow editorial use. Record the basis in `notes`.
